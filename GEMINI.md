# OMAR AI Project Documentation

## Overview
OMAR AI is a comprehensive AI platform featuring automation agents, computer vision capabilities, and a code execution sandbox.

## Tech Stack
- **Framework:** SvelteKit (Vite)
- **Language:** TypeScript
- **Styling:** TailwindCSS
- **Icons:** Lucide Svelte

## Features
- **Landing Page:** Modern dark-themed introduction.
- **Dashboard:** Overview of system status and active agents.
- **Agents:** Management interface for AI bots.
- **Computer Vision:** Image/Video upload and analysis simulation.
- **Sandbox:** Secure code execution environment simulation.

## Project Structure
- `src/routes/`: Application routes.
- `src/lib/components/`: Reusable UI components (Navbar, etc.).
- `src/app.css`: Global styles and Tailwind directives.

## Routes
- `/` - Home
- `/dashboard` - Dashboard
- `/agents` - Agent Management
- `/vision` - Computer Vision
- `/sandbox` - Code Sandbox

## Setup
1. `npm install`
2. `npm run dev`
