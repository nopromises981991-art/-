# OMAR AI

OMAR AI is a comprehensive web platform for AI Agents and Automation, inspired by Manus AI.

## Tech Stack
- **Framework**: SvelteKit (Svelte 5)
- **Styling**: Tailwind CSS v4
- **UI Components**: Shadcn Svelte (Bits UI) + Lucide Icons
- **Visualization**: Svelte Flow (for workflows)

## Features
- **Dashboard**: Real-time overview of agent activity and system status.
- **Agent Management**: Create, edit, and monitor AI agents.
- **Automation Workflow**: Visual node-based editor for creating automation sequences.
- **Vision Lab**: (Placeholder) Interface for computer vision tasks.
- **Sandbox**: (Placeholder) Secure environment for agent execution.

## Project Structure
- `src/routes/`: Application routes (File-based routing).
  - `dashboard/`: Protected dashboard area.
    - `agents/`: Agent management.
    - `automation/`: Workflow editor.
- `src/lib/components/ui/`: Reusable UI components.
- `src/lib/utils.ts`: Utility functions (cn).

## Setup
1. `bun install`
2. `bun dev`
